# MidstVritra

MidstVritra is a distributed, cloud-agnostic platform that employs real-time-processing auto-scaling to optimize system resources via a centralized orchestrator.

MidstVritra is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/MidstVritra.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

MidstVritra is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
